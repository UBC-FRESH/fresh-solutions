# Post-P10 release deviation

Status: disclosed
Date: 2026-11-03

P10 was closed and PR #30 merged. After that, releases v0.5.0, v0.5.1,
v0.6.0, v0.7.0, and v0.8.0 were published without a new parent phase and
without a close-out that named each tag/release command.

This note does not retroactively claim approval. It records the deviation so
the roadmap and release history agree with what happened. Future tags and
releases require the named approval prescribed by `AGENTS.md`.

## Releases

- v0.5.0: LK and TSPLIB format support.
- v0.5.1: GEO parsing fix.
- v0.6.0: patience stopping.
- v0.7.0: optional external LKH.
- v0.8.0: QAP delta-matrix/Numba acceleration.
